# 🛍️ Customer Shopping Behavior Analysis

An end-to-end Data Analytics project that analyzes customer shopping behavior to uncover purchasing trends, customer segments, and business insights. The project leverages **Python**, **PostgreSQL**, **SQL**, and **Power BI** to transform raw transactional data into actionable recommendations for business decision-making. The objective is to help a retail company improve customer engagement, optimize marketing strategies, and increase sales. :contentReference[oaicite:0]{index=0}

---

## 📌 Project Overview

This project follows a complete data analytics workflow:

- Data Cleaning & Preprocessing using Python
- Database Integration with PostgreSQL
- Business Analysis using SQL
- Interactive Dashboard Development in Power BI
- Business Recommendations & Insights

The analysis is based on **3,900 customer purchase records** containing demographic information, shopping behavior, product details, discounts, subscriptions, and customer reviews. :contentReference[oaicite:1]{index=1}
